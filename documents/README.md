# documents/

Put your real PDFs in this folder using these exact filenames so the links in
`index.html` work without any code changes:

- `cv.pdf` — your CV
- `thesis.pdf` — your thesis
- `research-statement.pdf` — research statement (if used)
- `teaching-statement.pdf` — teaching statement (if used)
- `paper-1.pdf`, `paper-2.pdf`, `paper-3.pdf` — PDFs for individual publications

This README is not part of the live site — delete it once your real
documents are in place, or leave it; GitHub Pages will simply ignore it.
